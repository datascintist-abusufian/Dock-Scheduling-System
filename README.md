# Dock Scheduling System

## Problem
The supplied workflow uses spreadsheet-based schedules spanning
1997–2019. Staff must manually identify reservation overlaps and
verify whether vessels fit assigned berths.

## Solution
A web-based reservation system providing:

• berth availability
• vessel-fit validation
• conflict detection
• vessel directory
• interactive dock schedule

## Assumptions
1. Berth length is treated as the primary physical fit constraint.
2. Reservations include both vessels and non-vessel events.
3. Date ranges are inclusive.
4. A berth cannot contain overlapping reservations.
5. Historical spreadsheet data contains inconsistent formatting,
   therefore representative records were normalised for the prototype.
